# Barbearia 248

Site institucional da Barbearia 248 — Meia Praia, Itapema, SC.

## Estrutura do projeto

```
barbearia248/
├── index.html          # Página principal
├── css/
│   └── style.css       # Todos os estilos
├── js/
│   └── main.js         # JavaScript (nav, carousel, lightbox, scroll)
└── images/             # Imagens do site
    ├── hero.jpg        # Foto principal do hero
    ├── diferenciais.jpg
    ├── galeria-1.jpg
    ├── galeria-2.jpg
    ├── galeria-3.jpg
    └── galeria-4.jpg
```

## Imagens

Substitua os arquivos na pasta `images/` pelas fotos reais da barbearia:

| Arquivo | Dimensão recomendada | Uso |
|---------|---------------------|-----|
| `hero.jpg` | 900×800px | Foto principal |
| `diferenciais.jpg` | 600×800px | Seção "A experiência 248" |
| `galeria-1.jpg` até `galeria-4.jpg` | 400×533px (3:4) | Grade da galeria |

## Funcionalidades

- Navegação responsiva com menu hamburguer mobile
- Animações de entrada ao rolar a página (IntersectionObserver)
- Carrossel de depoimentos com autoplay, dots, swipe touch e setas
- Lightbox para ampliar fotos da galeria
- Botão WhatsApp flutuante com animação de anel
- Mapa OpenStreetMap embutido
- Links diretos para WhatsApp e Google Maps
- 100% responsivo (mobile, tablet e desktop)
